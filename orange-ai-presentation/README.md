# نظام ذكي متكامل لفحص وتصنيف وفرز ثمار البرتقال آليا في خطوط الإنتاج

عرض تقديمي تفاعلي لمشروع تخرج — **جامعة صعدة** — تخصص **نظم المعلومات** — العام الجامعي **2026–2027**.

> منظومة ذكية تجمع الفحص البصري والتحكم الآلي وإدارة البيانات لتحسين جودة البرتقال ورفع كفاءة عمليات الفرز في خطوط الإنتاج.

**إعداد الطلاب**

- م/ عمران عبدالرحمن علي الشبح
- م/ عبدالرزاق علي عيظه شثان
- م/ يعقوب عمران قايد شويط

**إشراف**

- أ.م/ بكر الزني
- أ.م/ شاجع أبو علياء

---

## التشغيل

العرض صفحة ويب ثابتة تعمل بالكامل دون اتصال بالإنترنت.

### الطريقة الأسرع

افتح ملف `index.html` مباشرة بالمتصفح.

### عبر خادم محلي (مستحسن)

بعض المتصفحات تقيد تحميل الخطوط من نظام الملفات، لذلك يفضل تشغيل خادم محلي:

```bash
# Python 3
python3 -m http.server 8000

# أو Node.js
npx serve .
```

ثم افتح: `http://localhost:8000/index.html`

## اختصارات العرض

| المفتاح | الوظيفة |
| --- | --- |
| `→` | الشريحة التالية |
| `←` | الشريحة السابقة |
| `Space` | الشريحة التالية |
| `Home` | أول شريحة |
| `End` | آخر شريحة |
| `F` | ملء الشاشة |
| `O` | ملخص الشرائح |
| `Esc` | إغلاق الملخص |

على الهاتف: اسحب لليسار للانتقال إلى الشريحة التالية، ولليمين للعودة.

الرابط يحفظ رقم الشريحة، مثال: `index.html#9` يفتح الشريحة التاسعة مباشرة.

## العمل دون اتصال

لا يوجد أي طلب شبكة خارجي: لا CDN، ولا خطوط من Google، ولا أيقونات أو صور بعيدة. كل الأيقونات والرسوم مبنية بصيغة SVG داخل المشروع، والخطوط محفوظة محليا بصيغة `woff2`.

node tools/build-pdf.js

## ملاحظة عن شعار الجامعة

الشعار المستخدم في الغلاف والخاتمة رمز أصلي مصمم ضمن هوية العرض بصيغة SVG داخل `index.html` تحت المعرف `logo-saada`. لاستبداله بالشعار الرسمي للجامعة ضع ملف الشعار في `assets/img/` واستبدل عنصر `<svg><use href="#logo-saada" /></svg>` بعنصر `<img src="assets/img/logo.svg" alt="شعار جامعة صعدة">` في الموضعين.
