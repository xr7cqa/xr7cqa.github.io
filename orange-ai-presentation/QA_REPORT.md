## 7. Overflow Test — PASS

الشرط: لا يمكن تمرير أي شريحة، و `scrollWidth <= clientWidth` و `scrollHeight <= clientHeight`.

| المقاس | عدد الشرائح | حالات تمرير | ملاحظة |
| --- | --- | --- | --- |
| 1920×1080 | 14 | 0 | — |
| 1366×768 | 14 | 0 | — |
| 1280×720 | 14 | 0 | — |
| 844×390 | 14 | 0 | — |
| 915×412 | 14 | 0 | — |
| 390×844 | 14 | 0 | — |

**طريقة الفحص:** لكل عنصر يقص محتواه (`overflow` غير `visible`) يقارن `scrollWidth/scrollHeight` بـ `clientWidth/clientHeight`، ثم يجرب `scrollLeft = ±9999` و `scrollTop = 9999` ويقرأ القيمة للتأكد من عدم إمكانية التمرير فعليا.

**إصلاح مطبق:** استخدام `overflow: clip` بجانب `overflow: hidden` على `.deck` و `.slide` و `.slide__inner` لضمان انعدام منطقة التمرير نهائيا في المتصفحات الحديثة.

كذلك أعيدت صياغة انتقالات الشرائح لتكون كلها تصغيرا وإزاحة داخلية (`scale <= 1`) بدل الإزاحة الخارجة عن الإطار، حتى لا تولد الشرائح غير النشطة منطقة تمرير في `.deck`.

## 8. Overlap Test — PASS

**الطريقة:** تجمع كل العناصر التي تحمل نصا مباشرا وظاهرة فعليا، وتحسب مساحة التقاطع بين كل زوج غير مترابط بعلاقة أب وابن. أي تقاطع يتجاوز 12% من مساحة أصغر العنصرين يعد FAIL.

| المقاس | أزواج متداخلة |
| --- | --- |
| 1920×1080 | 0 |
| 1366×768 | 0 |
| 1280×720 | 0 |
| 844×390 | 0 |
| 915×412 | 0 |
| 390×844 | 0 |

**كذلك تم التحقق من:** عدم تداخل أي نص مع العنوان، وعدم تداخل أي نص مع شريط العرض السفلي، وذلك بحجز شريط سفلي داخل `.slide__inner` بمقدار `calc(var(--safe-y) * 0.5 + var(--chrome-h))`.

**تاريخ الإصلاحات:** رصد الفحص الأول 99 حالة (تداخل أسماء الطلاب مع العداد في الغلاف، وتداخل صندوق قاعدة البيانات مع النظام الرئيسي في شريحة التقنيات على الشاشات القصيرة، وتجاوز بطاقات المكونات لارتفاعها). أعيد بناء التخطيطات المعنية حتى وصل العدد إلى صفر.
